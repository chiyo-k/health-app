# マンホール商会 健康記録アプリ

健康経営の一環として、従業員が自分の **血圧・体重（BMI）** をスマホから記録し、
経理担当者が **Googleスプレッドシート** でまとめて確認・手当判定できるアプリです。
Google Apps Script（GAS）で動くため、サーバー代はかかりません（30人規模を想定）。

## できること

| 利用者 | できること |
| --- | --- |
| 従業員 | 社員番号＋暗証番号でログイン／血圧・体重・身長を記録（BMIは自動計算）／自分の判定結果と推移グラフの確認／暗証番号の変更 |
| 経理担当者（管理者） | 判定期（4月・10月）ごとの全員の一覧・提出状況・手当対象者の確認／個人の推移確認／「判定結果」シートへの書き出し／CSVダウンロード |

## 判定のルール

- 判定は **年2回（4月・10月）**。その月に測定した記録が判定に使われます（同じ月に複数あれば測定日が最も新しいもの）。
- それ以外の月の記録は **任意**（本人の健康管理・推移の確認用で、判定には使いません）。
- 次の3項目のうち **1つでもクリアすれば手当の対象** です。

| 項目 | クリアの条件 | 参考にした基準 |
| --- | --- | --- |
| 血圧 | 収縮期（上）130mmHg未満 **かつ** 拡張期（下）85mmHg未満 | 特定健診の保健指導判定値（130/85） |
| BMI | 18.5以上 25未満 | 特定健診・日本肥満学会の判定（25以上が肥満、18.5未満が低体重） |
| 体重 | **前回の判定測定**（4月なら前年10月、10月なら同年4月）から **3%以上減少** | 特定保健指導で「3%以上の減量で検査値の改善が見られる」とされる目安 |

- 体重は前回の判定測定がないとき（初回・前回未提出）は「判定なし」になります。
- 血圧が **受診勧奨判定値（140/90以上）** のときは、本人画面と管理画面に受診をすすめる表示が出ます（手当の判定とは別）。
- 出典：厚生労働省「標準的な健診・保健指導プログラム」。基準の数値は `Code.gs` 先頭の `CRITERIA` を書き換えるだけで変更できます。

## 導入手順（初回のみ・経理担当者または管理者）

1. Googleドライブで新しいスプレッドシートを作る（例：「健康記録」）。
2. メニュー「拡張機能」→「Apps Script」を開く。
3. 最初からある `コード.gs` の中身を消し、このフォルダの `Code.gs` の内容を貼り付ける。
4. 「＋」→「HTML」で `Index` という名前のファイルを作り、`Index.html` の内容を貼り付ける。
5. 左の「プロジェクトの設定」→「『appsscript.json』マニフェスト ファイルをエディタで表示する」にチェックし、`appsscript.json` の内容を貼り付ける（タイムゾーンを東京にするため）。
6. 関数 `setup` を選んで「実行」→ 権限の確認で許可する。
   スプレッドシートに「従業員」「記録」「判定結果」の3つのシートができます。
7. 「従業員」シートに30人分を入力する。

   | 社員番号 | 氏名 | 身長(cm) | 暗証番号 | 管理者 | 在籍 |
   | --- | --- | --- | --- | --- | --- |
   | 0001 | 見本 太郎 | 170 | 1234 | 管理者 | 在籍 |
   | 0002 | 山田 花子 | 158 | 5678 |  | 在籍 |

   - 暗証番号は4〜8桁の数字で、最初は経理担当者が決めて本人に配ります。初回ログイン時に自動で暗号化され、元の数字はシートから消えます（すぐ消したい場合はメニュー「健康記録アプリ」→「暗証番号を暗号化する」）。
   - 経理担当者の行の「管理者」列に何か入力（例：管理者）すると、アプリに「管理（全員）」タブが出ます。
   - 退職者は「在籍」列を `退職` にするとログインできなくなり、一覧からも外れます。
   - 見本の行（0001 見本 太郎）は不要になったら削除してください。
8. Apps Script 画面右上の「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 実行するユーザー：**自分**
   - アクセスできるユーザー：**全員**（従業員がGoogleアカウントを持っていなくても使えるようにするため。会社のGoogle Workspaceを全員が持っている場合は「（会社名）内の全員」を推奨）
9. 表示されたURLを従業員に配る（スマホのホーム画面に追加してもらうと便利です）。

> コードを修正したときは「デプロイを管理」→ 編集 → バージョン「新バージョン」で更新すると、URLは変わりません。

## 毎回の運用（4月・10月）

1. 月初に従業員へ「今月は判定月です」と周知（アプリにも表示されます）。
2. 月末にアプリの「管理（全員）」タブで提出状況を確認し、未提出者に声をかける（「未提出のみ表示」で絞り込み可能）。
3. 「『判定結果』シートに書き出す」を押すか、スプレッドシートのメニュー「健康記録アプリ」→「今期の判定結果を書き出す」で、手当対象者の一覧を保存。給与計算にはこの一覧またはCSVを使います。

## 個人情報の取り扱いについて（必ずお読みください）

血圧・体重などの健康情報は、個人情報保護法の **要配慮個人情報** にあたります。

- 利用目的（健康経営・手当の支給判定）を従業員に説明し、**同意を得てから** 運用を始めてください。
- スプレッドシートの共有は **経理担当者など必要最小限の人だけ** にしてください（従業員本人はアプリから自分の記録しか見られません）。
- アプリのURLを知っていても、社員番号と暗証番号がないとデータは見られません。暗証番号を5回続けて間違えると30分ログインできなくなります。
- 手当の判定以外の目的（人事評価など）には使わないことを社内ルールとして決めておくことをおすすめします。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `Code.gs` | サーバー側の処理（判定ロジック・シートの読み書き・ログイン） |
| `Index.html` | 従業員・経理担当者が使う画面 |
| `appsscript.json` | GASの設定（タイムゾーン・ウェブアプリ設定） |
| `docs/健康記録アプリの使い方_従業員向け.docx` | 従業員に配る使い方シート（A4・2枚） |
| `docs/健康記録アプリ_運用マニュアル_経理担当者向け.docx` | 経理担当者向けの運用マニュアル（A4・2枚） |
| `docs/make-guides.js` | 上の2つのWordファイルを作り直すスクリプト（`node docs/make-guides.js docs`。要 `docx` パッケージ） |

使い方シートのURL・QRコード・問い合わせ先は空欄です。デプロイ後に記入して配ってください。
